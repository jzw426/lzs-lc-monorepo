## 1 范围与边界

### 1.1 纳入范围

1. R-03 方案复审：评审报告 P0 3 项、P1 6 项、P2 5 项的关闭与复审结论。
2. LayaAir 3.3.0 工程、场景、脚本、类型检查、Lint 与 CI 落地。
3. 抖音开发者工具、Android/iOS 真机五类平台能力验证。
4. 三档设备性能采样、30 分钟稳定性与证据归档。
5. L3 结论签署及 M1 验收报告更新。

### 1.2 排除范围

1. M2 战斗、合成、八邻接拼字、突破与终局玩法。
2. L4 staging/production 部署与监控。
3. 正式美术、音频、商业化调优与正式广告结算。
4. 微信及其他平台适配。

### 1.3 关闭定义

L3 关闭必须同时满足：R-03/R-04 全部 P0/P1 用例通过、P2 通过率不低于 95%、三档性能中位数达标、五类能力 Android 与 iOS 均通过、黄金哈希一致、证据包完整、L3 结论签署完成。

## 9 闭环规则

### 9.1 任务完成定义（DoD）

1. 交付物已提交到 `feature/l3-laya-client` 或指定证据目录。
2. 验收标准有可复核证据，不以口头结论替代。
3. 相关命令退出码为 0，日志或截图已归档。
4. 有依赖关系的下游任务已收到完成通知。
5. 台账状态由 R7 更新为“已完成”。

### 9.2 状态口径

| 状态   | 含义                           |
| ------ | ------------------------------ |
| 未开始 | 前置未满足或未分配             |
| 进行中 | 已分配且有实际进展             |
| 阻塞   | 前置、资源或权限缺失，需升级   |
| 待验收 | 交付物完成，等待验收人确认     |
| 已完成 | 验收通过并登记证据             |
| 已取消 | 经 R1 批准不再执行，需写明原因 |

### 9.3 台账更新节奏

1. 每日：任务负责人更新状态与阻塞。
2. 每周：R7 输出进度、偏差与风险清单。
3. 里程碑：R1 复核达成判据，未达标不得推进下一里程碑。
