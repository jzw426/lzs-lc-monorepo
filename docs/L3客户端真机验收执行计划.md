## 1 验收目标与范围

### 1.1 验收目标

1. 证明 LayaAir 3.3.0 最小场景可以独立启动、渲染确定性快照并正确暴露视图边界（R-03）。
2. 证明抖音真机环境可以完成登录、激励广告、分享、存储、生命周期五类平台能力接入，且失败路径不伪造成功（R-04）。
3. 证明低、中、高三档真机上的帧率、内存、CPU、启动与渲染指标达到冻结阈值。
4. 形成可复核的设备、版本、原始采样数据与缺陷记录。

### 1.2 纳入范围

- LayaAir 3.3.0 最小 2D 场景、TypeScript 入口、快照渲染与事件消费。
- `@lzs/core`、`@lzs/client`、`@lzs/platform` 在客户端工程中的实际接入。
- 抖音开发者工具导入、真机预览、真机调试、性能面板与日志采集。
- Android 低/中端、iOS 高端至少各一台真机。
- R-03、R-04 专项用例及三档性能采样。

### 1.3 排除范围

- 完整战斗、合成、八邻接拼字、突破与终局玩法。
- 正式美术、音频、动画、商业化调优。
- 生产发布、灰度、正式支付与正式广告结算。
- 微信及其他平台适配。

### 3.4 网络环境

1. PC、真机连接同一 5GHz Wi-Fi，关闭 AP 隔离；PC 使用有线网络时，真机仍需能访问公网。
2. 关闭 VPN、系统代理、抓包代理；如必须抓包，需在测试记录中注明并单独判定性能数据无效。

## 4 LayaAir 最小可运行场景搭建

### 4.1 工程位置与依赖方式

- 工程目录：`e:\SmallGames\fkzyad\apps\laya-client`
- 包名：`@lzs/laya-client`
- 依赖：`@lzs/core`、`@lzs/client`、`@lzs/platform`，均使用 `workspace:*`
- 接入方式 A（优先）：pnpm workspace 软链 + 包导出。
- 接入方式 B（回退）：构建后将三个包的 `dist` 复制到 `apps/laya-client/libs/lzs/`，使用相对路径导入。

选择规则：优先执行方式 A；若 LayaAir 构建明确报模块解析失败，改用方式 B，并在测试记录中注明。不得同时混用两种方式。

### 4.2 安装 LayaAir IDE 3.3.0

1. 打开 LayaAir 官网下载页，选择 LayaAir 3.3.0 Windows 版本。
2. 安装到固定目录，例如 `D:\LayaAirIDE\3.3.0`。
3. 启动 IDE，打开“关于”，确认版本严格为 `3.3.0`。
4. 关闭自动更新，避免验收期间引擎版本漂移。
5. 记录安装路径与版本截图。

### 4.3 新建 LayaAir 项目

1. IDE 菜单选择“文件 → 新建项目”。
2. 项目类型选择“2D 项目”或“空项目”，语言选择 TypeScript。
3. 项目名称填写 `laya-client`，路径选择 `e:\SmallGames\fkzyad\apps`。
4. 引擎版本选择 3.3.0，点击创建。
5. 创建完成后确认目录中存在 IDE 生成的 `src`、`assets`、`settings`、`libs` 等结构；不得手工删除 IDE 生成的引擎库。
6. 在 IDE 中点击运行，确认空场景可启动。

### 4.4 加入 pnpm 工作区

编辑根目录 `pnpm-workspace.yaml`：

```yaml
packages:
  - packages/*
  - apps/*
```

在 `apps/laya-client/package.json` 中确认或补充：

```json
{
  "name": "@lzs/laya-client",
  "private": true,
  "version": "0.1.0",
  "type": "module",
  "dependencies": {
    "@lzs/core": "workspace:*",
    "@lzs/client": "workspace:*",
    "@lzs/platform": "workspace:*"
  }
}
```

执行：

```powershell
pnpm install
pnpm run build
```

通过条件：`apps/laya-client/node_modules/@lzs` 下出现三个软链，且 `packages/*/dist/index.js` 存在。

工作区变更与 `pnpm-lock.yaml` 必须一并提交到 `feature/l3-laya-client` 分支，确保其他测试机可复现安装结果。

### 4.6 最小场景入口代码

新建 `apps/laya-client/src/GameEntry.ts`，内容如下。该代码同时覆盖 R-03 的版本校验、快照渲染、视图异常隔离、黄金回放与测试入口。

```ts
import {
  GameSimulation,
  runReplay,
  type GameCommand,
  type GameEvent,
  type GameSnapshot,
  type Replay,
  type SimulationConfig,
} from '@lzs/core';
import { ClientRuntime, assertLayaAirVersion, type BattleView } from '@lzs/client';
import { MockPlatformAdapter, type PlatformAdapter, type RewardedAdResult } from '@lzs/platform';
import { DouyinPlatformAdapter } from './DouyinPlatformAdapter';

declare const Laya: any;
declare const tt: any;

const CONFIG: SimulationConfig = {
  seed: 20260304,
  initialGrain: 100,
  barracksCapacity: 5,
  recruitCost: 10,
  deck: ['刀', '枪', '骑', '弓'],
  versions: {
    gameVersion: '0.1.0-m1',
    contentVersion: 'content-m1.0',
    rulesVersion: 'rules-m1.0',
    configHash: 'fnv1a32:e7ae79c0',
  },
};

const GOLDEN_REPLAY: Replay = {
  config: CONFIG,
  totalTicks: 8,
  commands: [0, 1, 2, 3, 4, 5].map((tick) => ({
    type: 'recruit' as const,
    tick,
    sequence: 0,
    commandId: tick === 5 ? 'golden-full' : `golden-${tick}`,
  })) as GameCommand[],
  expectedHash: 'fnv1a32:92852f6a',
};

class StatusView implements BattleView {
  public failNextRender = false;

  public constructor(private readonly label: any) {}

  public render(snapshot: GameSnapshot): void {
    if (this.failNextRender) {
      this.failNextRender = false;
      throw new Error('L3_INJECTED_VIEW_ERROR');
    }
    const state = snapshot.state;
    const barracks = state.barracks.map((unit) => unit ?? '空').join(' | ');
    this.label.text =
      `tick=${state.tick}  粮草=${state.grain}\n` +
      `兵营=${barracks}\n` +
      `征兵成功=${state.successfulRecruits}  拒绝=${state.rejectedRecruits}`;
  }

  public present(events: readonly GameEvent[]): void {
    if (events.length > 0) {
      console.log('[L3_EVENTS]', JSON.stringify(events));
    }
  }
}

class GameEntry {
  private runtime!: ClientRuntime;
  private platform!: PlatformAdapter;
  private view!: StatusView;
  private lastSnapshot?: GameSnapshot;
  private rewardCount = 0;

  public async start(): Promise<void> {
    const version = String(Laya.version ?? Laya.Config?.version ?? '');
    assertLayaAirVersion(version);

    await Laya.init(750, 1334);
    Laya.stage.scaleMode = Laya.Stage.SCALE_FIXED_WIDTH;
    Laya.stage.alignH = Laya.Stage.ALIGN_CENTER;
    Laya.stage.alignV = Laya.Stage.ALIGN_MIDDLE;
    Laya.stage.bgColor = '#1b1b1b';

    const statusText = new Laya.Text();
    statusText.name = 'StatusText';
    statusText.fontSize = 32;
    statusText.color = '#ffffff';
    statusText.width = 670;
    statusText.height = 300;
    statusText.wordWrap = true;
    statusText.pos(40, 80);
    Laya.stage.addChild(statusText);

    this.platform = this.createPlatform();
    this.view = new StatusView(statusText);
    this.runtime = new ClientRuntime({
      simulation: new GameSimulation(CONFIG),
      view: this.view,
      platform: this.platform,
      onViewError: (error) => console.error('[L3_VIEW_ERROR]', error),
    });

    this.lastSnapshot = this.runtime.advanceTick();
    this.startLoop();
    this.exposeTestApi();
    this.createTestButtons();

    console.log(
      '[L3_BOOT_OK]',
      JSON.stringify({ version, configHash: CONFIG.versions.configHash }),
    );
  }

  private createPlatform(): PlatformAdapter {
    if (typeof tt !== 'undefined') {
      return new DouyinPlatformAdapter('替换为广告位ID');
    }
    return new MockPlatformAdapter();
  }

  private async showAd(): Promise<RewardedAdResult> {
    const result = await this.platform.showRewardedAd('替换为广告位ID');
    this.rewardCount += 1;
    console.log('[L3_REWARD_COUNT]', this.rewardCount);
    return result;
  }

  private createTestButtons(): void {
    const items = [
      { text: '登录', action: () => this.platform.login() },
      { text: '广告', action: () => this.showAd() },
      { text: '分享', action: () => this.platform.share('鲁智深与林冲 L3 验收') },
    ];
    items.forEach((item, index) => {
      const button = new Laya.Text();
      button.text = `[ ${item.text} ]`;
      button.fontSize = 32;
      button.color = '#7fd1ff';
      button.pos(40 + index * 170, 440);
      button.mouseEnabled = true;
      button.on(Laya.Event.CLICK, this, () => {
        Promise.resolve(item.action())
          .then((result) => console.log(`[L3_ACTION_OK] ${item.text}`, JSON.stringify(result)))
          .catch((error) => console.error(`[L3_ACTION_FAILED] ${item.text}`, error));
      });
      Laya.stage.addChild(button);
    });
  }

  private startLoop(): void {
    const stepMs = 1000 / 30;
    let accumulator = 0;
    Laya.timer.frameLoop(1, this, () => {
      accumulator += Laya.timer.delta;
      while (accumulator >= stepMs) {
        accumulator -= stepMs;
        this.lastSnapshot = this.runtime.advanceTick();
      }
    });
  }

  private exposeTestApi(): void {
    const api = {
      version: () => String(Laya.version ?? ''),
      hash: () => runReplay(GOLDEN_REPLAY).stateHash,
      replay: () => runReplay(GOLDEN_REPLAY),
      breakView: () => {
        this.view.failNextRender = true;
      },
      recruit: () => {
        const tick = this.lastSnapshot?.state.tick ?? 0;
        const command: GameCommand = {
          type: 'recruit',
          tick,
          sequence: 0,
          commandId: `l3-${tick}`,
        };
        this.lastSnapshot = this.runtime.advanceTick([command]);
        return this.lastSnapshot;
      },
      login: () => this.platform.login(),
      ad: () => this.showAd(),
      rewardCount: () => this.rewardCount,
      share: () => this.platform.share('鲁智深与林冲 L3 验收'),
      storageSet: (key: string, value: string) => this.platform.storage.set(key, value),
      storageGet: (key: string) => this.platform.storage.get(key),
      storageDelete: (key: string) => this.platform.storage.delete(key),
    };
    (globalThis as unknown as { __L3__: typeof api }).__L3__ = api;
  }
}

new GameEntry().start().catch((error) => {
  console.error('[L3_BOOT_FAILED]', error);
});
```

说明：

1. `assertLayaAirVersion` 在初始化前执行；版本不一致时直接抛出，不进入场景。
2. `ClientRuntime` 只把快照与事件交给 `StatusView`，视图无法取得 `GameSimulation`。
3. `breakView` 用于注入视图异常，验证核心模拟不中断。
4. `hash` 使用固定黄金回放，预期 `fnv1a32:92852f6a`。
5. 广告位 ID 必须替换为真实值；未替换时广告用例记为失败，不得记为通过。
6. 场景内提供“登录”“广告”“分享”三个可点击文本按钮；真机优先点击按钮触发，避免部分平台要求用户手势而控制台调用失败。

### 4.7 抖音适配器参考实现

新建 `apps/laya-client/src/DouyinPlatformAdapter.ts`。以下实现仅用于 L3 联调，登录用户映射不得用于生产。

```ts
import type {
  LifecycleHandlers,
  LoginResult,
  PlatformAdapter,
  RewardedAdResult,
  ShareResult,
  StoragePort,
} from '@lzs/platform';

declare const tt: any;

const SHARE_IMAGE = 'share.png';

export class DouyinPlatformAdapter implements PlatformAdapter {
  public readonly storage: StoragePort;
  private readonly ad: any;

  public constructor(adUnitId: string) {
    this.ad = tt.createRewardedVideoAd({ adUnitId });
    this.ad.onError((error: unknown) => console.error('[L3_AD_ERROR]', error));
    this.storage = {
      get: async (key) => {
        const value = tt.getStorageSync(key);
        return value === '' || value === undefined || value === null ? null : String(value);
      },
      set: async (key, value) => {
        tt.setStorageSync(key, value);
      },
      delete: async (key) => {
        tt.removeStorageSync(key);
      },
    };
  }

  public login(): Promise<LoginResult> {
    return new Promise((resolve, reject) => {
      tt.login({
        force: false,
        success: (result: { code?: string }) => {
          if (!result.code) {
            reject(new Error('L3_LOGIN_NO_CODE'));
            return;
          }
          resolve({
            userId: `l3-${result.code.slice(0, 8)}`,
            sessionToken: result.code,
          });
        },
        fail: (error: { errMsg?: string }) => {
          reject(new Error(`L3_LOGIN_FAILED:${error?.errMsg ?? 'unknown'}`));
        },
      });
    });
  }

  public async showRewardedAd(placementId: string): Promise<RewardedAdResult> {
    try {
      await this.ad.load();
    } catch {
      // 已加载或加载失败时继续 show，由 show 返回真实错误。
    }
    await this.ad.show();
    return new Promise((resolve, reject) => {
      const onClose = (result: { isEnded?: boolean }) => {
        this.ad.offClose(onClose);
        if (result?.isEnded) {
          resolve({ placementId, completed: true });
        } else {
          reject(new Error('L3_AD_CANCELLED'));
        }
      };
      this.ad.onClose(onClose);
    });
  }

  public share(content: string): Promise<ShareResult> {
    return new Promise((resolve, reject) => {
      tt.shareAppMessage({
        title: content,
        imageUrl: SHARE_IMAGE,
        success: () => resolve({ shared: true }),
        fail: (error: { errMsg?: string }) => {
          reject(new Error(`L3_SHARE_FAILED:${error?.errMsg ?? 'unknown'}`));
        },
      });
    });
  }

  public subscribeLifecycle(handlers: LifecycleHandlers): () => void {
    const onShow = () => handlers.onShow();
    const onHide = () => handlers.onHide();
    tt.onShow(onShow);
    tt.onHide(onHide);
    return () => {
      tt.offShow(onShow);
      tt.offHide(onHide);
    };
  }
}
```

注意：

1. `tt.login` 返回的 `code` 在 L3 中直接作为 `sessionToken`，仅用于验证平台调用链；生产环境必须由服务端换取会话，M2 实现。
2. 广告提前关闭必须拒绝，不得返回 `completed: true`。
3. 分享取消或失败必须拒绝，不得伪造 `shared: true`。
4. 所有错误日志不得输出 `code`、`sessionToken` 或用户标识全文。
5. 任一平台调用超过 15 秒未回调，记为 `L3_TIMEOUT`，判该用例失败；不得无限等待。

## 8 性能验收

### 8.1 指标阈值

以下阈值作为 L3 判定基线，自计划批准之日起冻结。测试期间不得调整；确需调整必须在采样开始前书面变更并重新批准。

| 指标                          | 低档         | 中档         | 高档         | 采样与统计                                              |
| ----------------------------- | ------------ | ------------ | ------------ | ------------------------------------------------------- |
| 平均 FPS                      | ≥30          | ≥45          | ≥55          | 稳态 120 秒，1 秒粒度，3 次中位数                       |
| 1% Low FPS                    | ≥24          | ≥35          | ≥45          | 帧时间第 99 百分位换算                                  |
| 帧时间 P95                    | ≤40ms        | ≤25ms        | ≤20ms        | 稳态 120 秒帧时间分布                                   |
| 渲染耗时 P95                  | ≤25ms        | ≤18ms        | ≤14ms        | LayaAir 统计或 Perfdog GPU；不可采集时以帧时间 P95 代替 |
| 卡顿率（帧时间 >50ms）        | ≤5%          | ≤3%          | ≤2%          | 卡顿帧数 / 总帧数                                       |
| 小游戏冷启动（onLaunch→首帧） | ≤5.0s        | ≤4.0s        | ≤3.0s        | 3 次冷启动中位数                                        |
| 小游戏热启动（回前台→首帧）   | ≤3.0s        | ≤2.5s        | ≤2.0s        | 3 次热启动中位数                                        |
| 游戏增量内存峰值              | ≤250MB       | ≤300MB       | ≤350MB       | PSS 峰值 − 抖音基线，3 次中位数                         |
| 30 分钟内存增长               | ≤10%         | ≤10%         | ≤10%         | `(结束值−10 秒值)/10 秒值`                              |
| CPU 平均                      | ≤40%         | ≤35%         | ≤30%         | 进程 CPU，稳态 120 秒                                   |
| CPU 峰值（1 秒）              | ≤70%         | ≤65%         | ≤60%         | 最大 1 秒均值                                           |
| Draw Call 峰值                | ≤100         | ≤100         | ≤120         | 每 10 秒采样，取最大值                                  |
| 三角形峰值                    | ≤50k         | ≤50k         | ≤80k         | 每 10 秒采样，取最大值                                  |
| 崩溃 / ANR                    | 0            | 0            | 0            | 30 分钟稳定性测试                                       |
| 主包大小                      | ≤平台上限90% | ≤平台上限90% | ≤平台上限90% | 开发者工具构建报告                                      |

说明：

1. 内存以“游戏增量”为主指标，避免把抖音宿主内存计入小游戏。
2. 若开发者工具性能面板不提供游戏内存，使用 Perfdog 进程 PSS 减去抖音首页基线，记录基线值。
3. CPU 与内存优先使用 Perfdog 发布包数据；开发者工具面板数据仅用于功能排查，不作为最终判定。
4. Draw Call 与三角形来自 LayaAir 调试统计或开发者工具性能面板，调试包数据仅用于上限判定，不参与 FPS 判定。
5. 任何指标“无法采集”均记为未通过，不得用主观描述替代。

### 8.2 采样环境

1. 设备电量 50%–80%，不充电；关闭省电模式与自动亮度。
2. 屏幕亮度 50%，音量 50%，关闭蓝牙、定位、后台同步。
3. 清理后台应用，强制停止抖音后重新启动。
4. 环境温度 25±5°C；设备表面温度高于 35°C 时暂停。
5. 同一设备、同一网络、同一构建产物完成全部采样。
6. Wi-Fi 使用 5GHz，PC 不占用大带宽；关闭下载与系统更新。

### 8.3 采样场景与时机

| 场景 | 操作                                       | 采样时长 | 用途                 |
| ---- | ------------------------------------------ | -------- | -------------------- |
| S1   | 强制停止抖音 → 点击图标 → 首帧             | 单次启动 | 冷启动               |
| S2   | 退出小游戏 → 立即回前台                    | 单次启动 | 热启动               |
| S3   | 首帧后静置                                 | 120 秒   | 空闲 FPS/内存/CPU    |
| S4   | 每 3 秒征兵一次，穿插面板开关与 2 次前后台 | 120 秒   | 脚本化稳态           |
| S5   | 循环 S4                                    | 30 分钟  | 稳定性与内存增长     |
| S6   | 飞行模式 → 恢复网络                        | 各 30 秒 | 网络异常恢复（可选） |

采样规则：

1. 每次运行前丢弃首帧后 10 秒数据，避免加载抖动。
2. 广告播放、系统弹窗、授权弹窗期间的数据不计入性能统计。
3. 每档设备至少 3 次有效运行；若 3 次中任一核心指标极差超过 10%，追加第 4 次。
4. 取 3 次（或 4 次）有效运行的中位数作为判定值。
5. 启动耗时使用 240fps 慢动作录像或应用内 `onLaunch` 到首帧时间戳；两者同时保留。
6. 内存每 10 秒采样一次；FPS/CPU 每 1 秒采样一次。
7. 所有原始数据导出 CSV，不得只保留截图。

### 8.4 统计规则

1. 平均 FPS：稳态区间内每秒 FPS 的算术平均值。
2. 1% Low FPS：将帧时间升序排列，取第 99 百分位帧时间 `T99`，按 `1000 / T99` 计算。
3. 帧时间 P95：第 95 百分位帧时间。
4. 卡顿率：帧时间大于 50ms 的帧数除以总帧数。
5. 内存增长：`(结束 PSS − 第 10 秒 PSS) / 第 10 秒 PSS × 100%`。
6. CPU 峰值：所有 1 秒窗口 CPU 使用率的最大值。
7. 启动耗时：从 `tt.onLaunch` 时间戳到首帧渲染完成时间戳；端到端耗时另记，不替代前者。
8. 中位数：奇数取中间值，偶数取中间两值平均。
9. 渲染耗时：优先取 LayaAir 独立渲染统计或 Perfdog GPU 时间；无法采集时使用帧时间 P95 代替，并在记录中注明“替代口径”。

## 9 判定标准

### 9.1 单用例判定

| 结果   | 条件                                                 |
| ------ | ---------------------------------------------------- |
| 通过   | 实际结果与预期完全一致，证据完整                     |
| 不通过 | 实际结果与预期不一致，或出现崩溃、伪造成功、静默失败 |
| 阻塞   | 环境或权限不具备，无法执行；必须记录阻塞原因与责任方 |
| 未采集 | 未执行或数据缺失；不得记为通过                       |

### 9.2 L3 通过条件

必须同时满足：

1. R-03、R-04 的所有 P0、P1 用例通过率 100%。
2. P2 用例通过率不低于 95%，且未通过项有责任人与规避方案。
3. P0/P1 缺陷数为 0；不存在崩溃、ANR、伪造平台成功、确定性哈希不一致。
4. 低、中、高三档设备的全部性能门槛指标中位数达标；任一门槛指标不达标即 L3 不通过。
5. 五类平台能力在至少一台 Android 与一台 iOS 真机上通过。
6. 真机 `stateHash` 与黄金样本 `fnv1a32:92852f6a` 一致。
7. 证据包完整：设备信息、版本、构建哈希、原始 CSV、截图、录屏、日志、缺陷清单。

### 9.3 有条件通过与不通过

- **有条件通过**：仅允许 P2 级界面/文案问题，且不影响任何 P0/P1 用例、不涉及性能门槛；必须登记责任人与关闭标准。
- **不通过**：出现任一 P0/P1 缺陷、任一性能门槛未达标、平台能力缺失、哈希不一致、证据缺失或无法复现。
- **待验收**：设备、AppID、广告位或网络任一前置条件缺失，导致关键用例无法执行。

### 9.4 复测规则

1. 环境问题导致失败：修复环境后完整重跑该用例，不改变判定阈值。
2. 代码修复导致失败：重新构建并重跑受影响用例及相关性能采样。
3. 性能不达标：允许在同构建、同设备、同环境下复测 1 次；仍不达标则判定不通过，不得通过更换设备规避。
4. 任何复测必须保留原始失败记录，不得覆盖。
