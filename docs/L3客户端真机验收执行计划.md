## 1 验收目标与范围

### 1.1 验收目标

1. 证明 LayaAir 3.3.0 最小场景可以独立启动、渲染确定性快照并正确暴露视图边界（R-03）。
2. 证明抖音真机环境可以完成登录、激励广告、分享、存储、生命周期五类平台能力接入，且失败路径不伪造成功（R-04）。
3. 证明低、中、高三档真机上的帧率、内存、CPU、启动与渲染指标达到冻结阈值。
4. 形成可复核的设备、版本、原始采样数据与缺陷记录。

### 1.2 纳入范围

- LayaAir 3.3.0 最小 2D 场景、TypeScript 入口、快照渲染与事件消费。
- `@lzs/core`、`@lzs/client`、`@lzs/platform` 在客户端工程中的实际接入。
- 抖音开发者工具导入、真机预览、真机调试、性能面板与日志采集。
- Android 低/中端、iOS 高端至少各一台真机。
- R-03、R-04 专项用例及三档性能采样。

### 1.3 排除范围

- 完整战斗、合成、八邻接拼字、突破与终局玩法。
- 正式美术、音频、动画、商业化调优。
- 生产发布、灰度、正式支付与正式广告结算。
- 微信及其他平台适配。

## 4 LayaAir 最小可运行场景搭建

> v1.1 采用**场景驱动**：`Main.scene` 是唯一 UI 根，`GameScene` 作为脚本挂在场景根节点，代码只查找、绑定与更新节点，不创建 `StatusText`、`ActionBar` 或按钮，也不调用 `Laya.init`、`Laya.stage.addChild`。第 14 章给出评审意见的逐条处理位置。

### 4.1 工程位置与依赖方式

- 工程目录：`e:\SmallGames\fkzyad\apps\laya-client`
- 包名：`@lzs/laya-client`
- 依赖：`@lzs/core`、`@lzs/client`、`@lzs/platform`，均使用 `workspace:*`
- 接入方式 A（优先）：pnpm workspace 软链 + 包导出。
- 接入方式 B（回退）：构建后将三个包的 `dist` 复制到 `apps/laya-client/libs/lzs/`，使用相对路径导入。

选择规则：优先执行方式 A；若 LayaAir 构建明确报模块解析失败，改用方式 B，并在测试记录中注明。不得同时混用两种方式。

### 4.2 安装 LayaAir IDE 3.3.0

1. 打开 LayaAir 官网下载页，选择 LayaAir 3.3.0 Windows 版本。
2. 安装到固定目录，例如 `D:\LayaAirIDE\3.3.0`。
3. 启动 IDE，打开“关于”，确认版本严格为 `3.3.0`。
4. 关闭自动更新，避免验收期间引擎版本漂移。
5. 记录安装路径与版本截图。

### 4.3 新建 LayaAir 项目

1. IDE 菜单选择“文件 → 新建项目”。
2. 项目类型选择“2D 项目”或“空项目”，语言选择 TypeScript。
3. 项目名称填写 `laya-client`，路径选择 `e:\SmallGames\fkzyad\apps`。
4. 引擎版本选择 3.3.0，点击创建。
5. 创建完成后确认目录中存在 IDE 生成的 `src`、`assets`、`settings`、`libs` 等结构；不得手工删除 IDE 生成的引擎库。
6. 在 IDE 中点击运行，确认空场景可启动。

### 4.4 加入 pnpm 工作区

编辑根目录 `pnpm-workspace.yaml`：

```yaml

  - packages/*
  - apps/*
```

在 `apps/laya-client/package.json` 中确认或补充：

```json

  "private": true,
  "version": "0.1.0",
  "type": "module",
  "dependencies": {
    "@lzs/core": "workspace:*",
    "@lzs/client": "workspace:*",
    "@lzs/platform": "workspace:*"
```

执行：

```powershell

```

通过条件：`apps/laya-client/node_modules/@lzs` 下出现三个软链，且 `packages/*/dist/index.js` 存在。

工作区变更与 `pnpm-lock.yaml` 必须一并提交到 `feature/l3-laya-client` 分支，确保其他测试机可复现安装结果。

### 4.4.1 类型检查、Lint 与 CI 接入

`apps/laya-client` 必须纳入类型检查与 Lint，避免 `advanceTick` 返回值误用等问题再次进入方案或代码。

1. 在 IDE 生成的 `apps/laya-client/tsconfig.json` 基础上确认开启严格模式与装饰器：

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "strict": true,
    "noEmit": true,
    "experimentalDecorators": true,
    "skipLibCheck": true
  },
  "include": ["src/**/*.ts", "libs/**/*.d.ts"]
}
```

> LayaAir 类型声明（IDE 生成的 `libs/*.d.ts`，若 3.3.0 生成在 `types/` 则以实际目录为准）必须保留并纳入版本控制，类型检查才可在 CI 复现。B-01 完成后必须确认实际目录并固定 `include`，禁止用 `declare const Laya: any` 绕过类型。
>
> `typecheck` 脚本依赖工作区根 `typescript`。若 `pnpm -r --if-present typecheck` 报找不到 `tsc`，在 `apps/laya-client` 的 `devDependencies` 声明 `typescript@5.9.3`，不得改用全局安装。

2. 在 `apps/laya-client/package.json` 增加脚本：

```json
{
  "scripts": {
    "typecheck": "tsc --noEmit -p tsconfig.json"
  }
}
```

3. 根命令 `pnpm run typecheck` 通过 `pnpm -r --if-present typecheck` 自动覆盖该应用；根 `pnpm run ci` 已包含 Lint、类型检查与构建，因此第 2.1 节 E-07 的通过条件必须包含本应用。
4. 在根 [eslint.config.mjs](file:///e:/SmallGames/fkzyad/eslint.config.mjs) 增加应用级覆盖，并把 `libs/`、`dist/` 加入忽略：

```js
{
  files: ['apps/laya-client/src/**/*.ts'],
  languageOptions: {
    globals: { Laya: 'readonly', tt: 'readonly' },
  },
  rules: {
    'no-undef': 'off',
    'no-restricted-imports': ['error', { patterns: ['@lzs/server*', '@lzs/tools*'] }],
  },
}
```

5. 根 `pnpm run ci` 的第一步是 `format:check`。必须在 `.prettierignore` 中排除 IDE 生成物与构建产物，否则云端 CI 会因引擎库或场景文件格式不一致而失败：

```gitignore
apps/laya-client/libs/
apps/laya-client/types/
apps/laya-client/dist/
apps/laya-client/assets/
apps/laya-client/settings/
```

6. 本地门禁命令（与云端 CI 等价）：

```powershell
pnpm exec prettier --check "apps/laya-client/src/**/*.ts"
pnpm exec tsc --noEmit -p apps/laya-client/tsconfig.json
pnpm exec eslint apps/laya-client/src
```

通过条件：三条命令退出码均为 0；业务代码中 `any` 数量为 0（仅 `src/types/*.d.ts` 允许必要的平台声明）。

#### 4.5.1 场景树与节点属性

`Main.scene` 是唯一 UI 根，节点层级、命名与尺寸固定如下。代码按名称查找节点，改名视为破坏性变更。

```text
Main.scene (Scene2D, 750×1334, 挂载 GameScene)
├─ Background (Sprite, 0,0,750,1334)
└─ UIRoot (Sprite, 0,0,750,1334)
   ├─ StatusText (Text, 40,80,670,300)
   └─ ActionBar (Sprite, 40,440,670,80)
      ├─ LoginButton (Sprite, 0,0,150,60)
      │  └─ LoginLabel (Text, 150×60)
      ├─ AdButton (Sprite, 170,0,150,60)
      │  └─ AdLabel (Text, 150×60)
      └─ ShareButton (Sprite, 340,0,150,60)
         └─ ShareLabel (Text, 150×60)
```

| 节点        | 类型   | 位置与尺寸    | 关键属性                                                |
| ----------- | ------ | ------------- | ------------------------------------------------------- |
| Main        | 根节点 | 750×1334      | 挂载脚本 `GameScene`                                    |
| Background  | Sprite | 0,0,750,1334  | `graphics.drawRect` 填充 `#1b1b1b`，不依赖图片          |
| UIRoot      | Sprite | 0,0,750,1334  | UI 容器，运行时按安全区整体下移                         |

#### 4.5.3 安全区

1. `UIRoot` 初始位置为 `(0,0)`，设计稿顶部留白 40px 已包含在 `StatusText.y=80` 中。
2. `GameScene.onAwake` 读取 `tt.getSystemInfoSync().safeArea.top` 与 `screenHeight`，按 `Laya.stage.height / screenHeight` 换算到设计坐标。
3. 当换算后的安全区顶部大于 40px 时，把 `UIRoot.y` 设为差值，避免刘海遮挡；小于等于 40px 时不偏移。

#### 4.6.1 `src/StatusView.ts`

```ts
import type { BattleView } from '@lzs/client';
import type { GameEvent, GameSnapshot } from '@lzs/core';

const REFRESH_INTERVAL_TICKS = 5;

export class StatusView implements BattleView {
  public failNextRender = false;
  private snapshot?: GameSnapshot;
  private hint = '';

  public constructor(
    private readonly label: Laya.Text,
    private readonly debugLog: boolean,
  ) {}

  public render(snapshot: GameSnapshot): void {
    this.snapshot = snapshot;
    if (this.failNextRender) {
      this.failNextRender = false;
      throw new Error('L3_INJECTED_VIEW_ERROR');
    }
    const tick = snapshot.state.tick;
    if (tick > 1 && tick % REFRESH_INTERVAL_TICKS !== 0) {
      return;
    }
    this.flush();
  }

  public present(events: readonly GameEvent[]): void {
    if (this.debugLog && events.length > 0) {
      console.log('[L3_EVENTS]', JSON.stringify(events));
    }
  }

  public setHint(text: string): void {
    this.hint = text;
    this.flush();
  }

  private flush(): void {
    const snapshot = this.snapshot;
    if (snapshot === undefined) {
      return;
    }
    const state = snapshot.state;
    const barracks = state.barracks.map((unit) => unit ?? '空').join(' | ');
    this.label.text =
      `tick=${state.tick}  粮草=${state.grain}\n` +
      `兵营=${barracks}\n` +
      `征兵成功=${state.successfulRecruits}  拒绝=${state.rejectedRecruits}\n` +
      `配置=${snapshot.config.versions.configHash}\n` +
      `动作=${this.hint.length > 0 ? this.hint : '无'}`;
  }
}
```

#### 4.6.2 `src/GameScene.ts`

```ts
import {
  GameSimulation,
  runReplay,
  type GameCommand,
  type GameSnapshot,
  type Replay,
  type SimulationConfig,
} from '@lzs/core';
import { ClientRuntime, assertLayaAirVersion } from '@lzs/client';
import { MockPlatformAdapter, type PlatformAdapter, type RewardedAdResult } from '@lzs/platform';
import { DouyinPlatformAdapter } from './DouyinPlatformAdapter';
import { StatusView } from './StatusView';

const { regClass } = Laya;

const STEP_MS = 1000 / 30;
const MAX_DELTA_MS = 100;
const MAX_ACCUMULATOR_MS = 200;
const DESIGN_TOP_MARGIN = 40;
const AD_PLACEMENT_ID = '替换为广告位ID';
const SHARE_TEXT = '鲁智深与林冲 L3 验收';
const DEBUG_LOG = false;

const CONFIG: SimulationConfig = {
  seed: 20260304,
  initialGrain: 100,
  barracksCapacity: 5,
  recruitCost: 10,
  deck: ['刀', '枪', '骑', '弓'],
  versions: {
    gameVersion: '0.1.0-m1',
    contentVersion: 'content-m1.0',
    rulesVersion: 'rules-m1.0',
    configHash: 'fnv1a32:e7ae79c0',
  },
};

const GOLDEN_REPLAY: Replay = {
  config: CONFIG,
  totalTicks: 8,
  commands: [0, 1, 2, 3, 4, 5].map((tick) => ({
    type: 'recruit' as const,
    tick,
    sequence: 0,
    commandId: tick === 5 ? 'golden-full' : `golden-${tick}`,
  })) as GameCommand[],
  expectedHash: 'fnv1a32:92852f6a',
};

@regClass()
export class GameScene extends Laya.Script {
  private runtime!: ClientRuntime;
  private platform!: PlatformAdapter;
  private view!: StatusView;
  private lastSnapshot?: GameSnapshot;
  private engineVersion = '';
  private ready = false;
  private paused = false;
  private accumulator = 0;
  private rewardCount = 0;
  private unsubscribe?: () => void;
  private readonly boundButtons: { node: Laya.Sprite; handler: () => void }[] = [];

  public onAwake(): void {
    try {
      this.bootstrap();
    } catch (error) {
      console.error('[L3_BOOT_FAILED]', error);
      throw error;
    }
  }

  public onUpdate(): void {
    if (!this.ready || this.paused) {
      return;
    }
    const delta = Math.min(Laya.timer.delta, MAX_DELTA_MS);
    this.accumulator = Math.min(this.accumulator + delta, MAX_ACCUMULATOR_MS);
    while (this.accumulator >= STEP_MS) {
      this.accumulator -= STEP_MS;
      this.lastSnapshot = this.runtime.advanceTick().snapshot;
    }
  }

  public onDestroy(): void {
    this.ready = false;
    this.unsubscribe?.();
    this.unsubscribe = undefined;
    for (const { node, handler } of this.boundButtons) {
      node.off(Laya.Event.CLICK, this, handler);
    }
    this.boundButtons.length = 0;
    delete (globalThis as { __L3__?: unknown }).__L3__;
  }

  private bootstrap(): void {
    this.engineVersion = this.readEngineVersion();

    const uiRoot = this.requireNode<Laya.Sprite>(this.owner, 'UIRoot');
    const statusText = this.requireNode<Laya.Text>(uiRoot, 'StatusText');
    const actionBar = this.requireNode<Laya.Sprite>(uiRoot, 'ActionBar');
    this.applySafeArea(uiRoot);

    this.platform = this.createPlatform();
    this.view = new StatusView(statusText, DEBUG_LOG);
    this.runtime = new ClientRuntime({
      simulation: new GameSimulation(CONFIG),
      view: this.view,
      platform: this.platform,
      onViewError: (error) => console.error('[L3_VIEW_ERROR]', error),
    });

    this.lastSnapshot = this.runtime.advanceTick().snapshot;
    this.unsubscribe = this.platform.subscribeLifecycle({
      onHide: () => {
        this.paused = true;
        this.accumulator = 0;
      },
      onShow: () => {
        this.paused = false;
        this.accumulator = 0;
      },
    });

    this.bindButton(this.requireNode<Laya.Sprite>(actionBar, 'LoginButton'), '登录', () =>
      this.platform.login(),
    );
    this.bindButton(this.requireNode<Laya.Sprite>(actionBar, 'AdButton'), '广告', () =>
      this.showAd(),
    );
    this.bindButton(this.requireNode<Laya.Sprite>(actionBar, 'ShareButton'), '分享', () =>
      this.platform.share(SHARE_TEXT),
    );

    this.exposeTestApi();
    this.ready = true;
    console.log(
      '[L3_BOOT_OK]',
      JSON.stringify({ version: this.engineVersion, configHash: CONFIG.versions.configHash }),
    );
  }

  private readEngineVersion(): string {
    const version = (Laya as unknown as { version?: string }).version ?? '';
    if (version.length === 0) {
      throw new Error('L3_ENGINE_VERSION_UNKNOWN');
    }
    assertLayaAirVersion(version);
    return version;
  }

  private requireNode<T extends Laya.Node>(root: Laya.Node, name: string): T {
    const node = root.getChildByName(name) as T | null;
    if (node === null) {
      throw new Error(`L3_SCENE_NODE_MISSING:${name}`);
    }
    return node;
  }

  private applySafeArea(uiRoot: Laya.Sprite): void {
    if (typeof tt === 'undefined') {
      return;
    }
    const info = tt.getSystemInfoSync();
    const safeTop = info.safeArea?.top ?? 0;
    const screenHeight = info.screenHeight ?? 0;
    if (safeTop <= 0 || screenHeight <= 0) {
      return;
    }
    const designSafeTop = (safeTop * Laya.stage.height) / screenHeight;
    uiRoot.y = Math.max(0, designSafeTop - DESIGN_TOP_MARGIN);
  }

  private createPlatform(): PlatformAdapter {
    return typeof tt === 'undefined'
      ? new MockPlatformAdapter()
      : new DouyinPlatformAdapter(AD_PLACEMENT_ID);
  }

  private async showAd(): Promise<RewardedAdResult> {
    const result = await this.platform.showRewardedAd(AD_PLACEMENT_ID);
    this.rewardCount += 1;
    console.log('[L3_REWARD_COUNT]', this.rewardCount);
    return result;
  }

  private bindButton(node: Laya.Sprite, name: string, action: () => unknown): void {
    const handler = (): void => {
      this.runAction(name, action);
    };
    node.mouseEnabled = true;
    node.on(Laya.Event.CLICK, this, handler);
    this.boundButtons.push({ node, handler });
  }

  private runAction(name: string, action: () => unknown): void {
    this.view.setHint(`${name}执行中`);
    Promise.resolve()
      .then(() => action())
      .then(() => {
        console.log(`[L3_ACTION_OK] ${name}`);
        this.view.setHint(`${name}成功`);
      })
      .catch((error: unknown) => {
        console.error(`[L3_ACTION_FAILED] ${name}`, error);
        const message = error instanceof Error ? error.message : String(error);
        this.view.setHint(`${name}失败：${message}`);
      });
  }

  private exposeTestApi(): void {
    const api = {
      version: () => this.engineVersion,
      hash: () => runReplay(GOLDEN_REPLAY).stateHash,
      replay: () => runReplay(GOLDEN_REPLAY),
      breakView: () => {
        this.view.failNextRender = true;
      },
      recruit: () => {
        const tick = this.lastSnapshot?.state.tick ?? 0;
        const command: GameCommand = {
          type: 'recruit',
          tick,
          sequence: 0,
          commandId: `l3-${tick}`,
        };
        const result = this.runtime.advanceTick([command]);
        this.lastSnapshot = result.snapshot;
        return result;
      },
      login: () => this.platform.login(),
      ad: () => this.showAd(),
      rewardCount: () => this.rewardCount,
      share: () => this.platform.share(SHARE_TEXT),
      storageSet: (key: string, value: string) => this.platform.storage.set(key, value),
      storageGet: (key: string) => this.platform.storage.get(key),
      storageDelete: (key: string) => this.platform.storage.delete(key),
    };
    (globalThis as unknown as { __L3__: typeof api }).__L3__ = api;
  }
}
```

#### 4.6.3 实现约束

1. 场景节点是唯一来源：`StatusText`、`ActionBar`、三个按钮全部来自 `Main.scene`；节点缺失时抛出 `L3_SCENE_NODE_MISSING:<name>` 并终止启动。
2. 不调用 `Laya.init`、不调用 `Laya.stage.addChild`、不 `new Laya.Text()` 创建 UI；引擎初始化与场景加载由 IDE 启动流程负责。
3. 版本在 `onAwake` 读取：空值抛 `L3_ENGINE_VERSION_UNKNOWN`，非 3.3.0 由 `assertLayaAirVersion` 抛出 `LayaAir版本不一致`。两者必须可区分。
4. `advanceTick()` 一律取 `.snapshot`；`recruit()` 返回完整 `ClientTickResult`，不得把结果直接赋给快照字段。
5. 生命周期：`onHide` 暂停并清空累加器，`onShow` 恢复并清空累加器；帧 delta 上限 100ms，累加器上限 200ms，防止回前台追帧。
6. 文本每 5 tick 刷新一次（6Hz）；`DEBUG_LOG` 在性能构建中必须为 `false`，调试包可置 `true`，性能数据只认关闭日志的构建。
7. 按钮统一 150×60，`mouseEnabled=true`，绑定与解绑使用同一 handler 引用；动作成功/失败必须写回状态文本并输出 `[L3_ACTION_OK]` / `[L3_ACTION_FAILED]`。
8. `onDestroy` 必须取消生命周期订阅、解绑全部按钮、删除 `globalThis.__L3__`；除 `__L3__` 外不写全局。
9. 日志不得输出完整 `code`、`sessionToken`、用户标识；`runAction` 只记录动作名与错误消息。

#### 4.7.2 `src/DouyinPlatformAdapter.ts`

```ts
import type {
  LifecycleHandlers,
  LoginResult,
  PlatformAdapter,
  RewardedAdResult,
  ShareResult,
  StoragePort,
} from '@lzs/platform';

const SHARE_IMAGE = 'share.png';
const AD_SHOW_TIMEOUT_MS = 15_000;
const AD_PLAY_TIMEOUT_MS = 120_000;

export class DouyinPlatformAdapter implements PlatformAdapter {
  public readonly storage: StoragePort;
  private readonly ad: TTRewardedVideoAd;

  public constructor(adUnitId: string) {
    this.ad = tt.createRewardedVideoAd({ adUnitId });
    this.ad.onError((error) => {
      console.error('[L3_AD_ERROR]', error.errCode ?? 'unknown', error.errMsg ?? 'unknown');
    });
    this.storage = {
      get: async (key) => {
        const value = tt.getStorageSync(key);
        return value === '' || value === undefined || value === null ? null : String(value);
      },
      set: async (key, value) => {
        tt.setStorageSync(key, value);
      },
      delete: async (key) => {
        tt.removeStorageSync(key);
      },
    };
  }

  public login(): Promise<LoginResult> {
    return new Promise((resolve, reject) => {
      tt.login({
        force: false,
        success: (result) => {
          if (!result.code) {
            reject(new Error('L3_LOGIN_NO_CODE'));
            return;
          }
          resolve({
            userId: `l3-${result.code.slice(0, 8)}`,
            sessionToken: result.code,
          });
        },
        fail: (error) => {
          reject(new Error(`L3_LOGIN_FAILED:${error.errMsg ?? 'unknown'}`));
        },
      });
    });
  }

  public showRewardedAd(placementId: string): Promise<RewardedAdResult> {
    return new Promise((resolve, reject) => {
      let settled = false;
      let timer: ReturnType<typeof setTimeout> | undefined;

      const finish = (action: () => void): void => {
        if (settled) {
          return;
        }
        settled = true;
        if (timer !== undefined) {
          clearTimeout(timer);
        }
        this.ad.offClose(onClose);
        action();
      };
      const startTimer = (ms: number, message: string): void => {
        if (timer !== undefined) {
          clearTimeout(timer);
        }
        timer = setTimeout(() => finish(() => reject(new Error(message))), ms);
      };
      const onClose = (result: { isEnded?: boolean }): void => {
        if (result.isEnded === true) {
          finish(() => resolve({ placementId, completed: true }));
        } else {
          finish(() => reject(new Error('L3_AD_CANCELLED')));
        }
      };

      // 先注册回调再 show，避免用户快速关闭时错过 onClose。
      startTimer(AD_SHOW_TIMEOUT_MS, 'L3_AD_TIMEOUT');
      this.ad.onClose(onClose);
      this.ad
        .load()
        .catch(() => undefined)
        .then(() => this.ad.show())
        .then(() => {
          // 展示成功后进入播放阶段，避免 30 秒以上广告被启动超时误杀。
          if (!settled) {
            startTimer(AD_PLAY_TIMEOUT_MS, 'L3_AD_PLAY_TIMEOUT');
          }
        })
        .catch((error: { errCode?: number }) => {
          finish(() => reject(new Error(`L3_AD_FAILED:${error.errCode ?? 'unknown'}`)));
        });
    });
  }

  public share(content: string): Promise<ShareResult> {
    return new Promise((resolve, reject) => {
      tt.shareAppMessage({
        title: content,
        imageUrl: SHARE_IMAGE,
        success: () => resolve({ shared: true }),
        fail: (error) => {
          reject(new Error(`L3_SHARE_FAILED:${error.errMsg ?? 'unknown'}`));
        },
      });
    });
  }

  public subscribeLifecycle(handlers: LifecycleHandlers): () => void {
    const onShow = (): void => handlers.onShow();
    const onHide = (): void => handlers.onHide();
    tt.onShow(onShow);
    tt.onHide(onHide);
    return () => {
      tt.offShow(onShow);
      tt.offHide(onHide);
    };
  }
}
```

#### 4.7.3 约束

1. `tt.login` 返回的 `code` 在 L3 中直接作为 `sessionToken`，仅用于验证平台调用链；生产环境必须由服务端换取会话，M2 实现。
2. 广告提前关闭必须拒绝（`L3_AD_CANCELLED`），不得返回 `completed: true`；`onClose` 必须先于 `show` 注册，防止快速关闭竞态。
3. 广告加载或展示启动超过 15 秒为 `L3_AD_TIMEOUT`；展示成功后的播放阶段上限 120 秒，超时为 `L3_AD_PLAY_TIMEOUT`；两类超时均须清理定时器与监听。
4. 分享取消或失败必须拒绝，不得伪造 `shared: true`；`imageUrl` 使用包根 `share.png`，构建后必须存在（见 4.9）。
5. 所有错误日志不得输出 `code`、`sessionToken` 或用户标识全文。
6. `subscribeLifecycle` 返回的取消函数必须由 `GameScene.onDestroy` 调用；重复订阅视为缺陷。
7. 登录、分享、存储调用超过 15 秒未回调判该用例失败；广告按“启动 15 秒、播放 120 秒”判定，不得无限等待。

| 三角形峰值                    | ≤50k         | ≤50k         | ≤80k         | 每 10 秒采样，取最大值                                  |

说明：

1. 内存以“游戏增量”为主指标，避免把抖音宿主内存计入小游戏。
2. 若开发者工具性能面板不提供游戏内存，使用 Perfdog 进程 PSS 减去抖音首页基线，记录基线值。
3. CPU 与内存优先使用 Perfdog 发布包数据；开发者工具面板数据仅用于功能排查，不作为最终判定。
4. Draw Call 与三角形来自 LayaAir 调试统计或开发者工具性能面板，调试包数据仅用于上限判定，不参与 FPS 判定。
5. 任何指标“无法采集”均记为未通过，不得用主观描述替代。

### 8.2 采样环境

1. 设备电量 50%–80%，不充电；关闭省电模式与自动亮度。
2. 屏幕亮度 50%，音量 50%，关闭蓝牙、定位、后台同步。
3. 清理后台应用，强制停止抖音后重新启动。
4. 环境温度 25±5°C；设备表面温度高于 35°C 时暂停。
5. 同一设备、同一网络、同一构建产物完成全部采样。
6. Wi-Fi 使用 5GHz，PC 不占用大带宽；关闭下载与系统更新。

### 8.3 采样场景与时机

| 场景 | 操作                                       | 采样时长 | 用途                 |
| ---- | ------------------------------------------ | -------- | -------------------- |
| S1   | 强制停止抖音 → 点击图标 → 首帧             | 单次启动 | 冷启动               |
| S2   | 退出小游戏 → 立即回前台                    | 单次启动 | 热启动               |
| S3   | 首帧后静置                                 | 120 秒   | 空闲 FPS/内存/CPU    |
| S4   | 每 3 秒征兵一次，穿插面板开关与 2 次前后台 | 120 秒   | 脚本化稳态           |
| S5   | 循环 S4                                    | 30 分钟  | 稳定性与内存增长     |
| S6   | 飞行模式 → 恢复网络                        | 各 30 秒 | 网络异常恢复（可选） |

采样规则：

1. 每次运行前丢弃首帧后 10 秒数据，避免加载抖动。
2. 广告播放、系统弹窗、授权弹窗期间的数据不计入性能统计。
3. 每档设备至少 3 次有效运行；若 3 次中任一核心指标极差超过 10%，追加第 4 次。
4. 取 3 次（或 4 次）有效运行的中位数作为判定值。
5. 启动耗时使用 240fps 慢动作录像或应用内 `onLaunch` 到首帧时间戳；两者同时保留。
6. 内存每 10 秒采样一次；FPS/CPU 每 1 秒采样一次。
7. 所有原始数据导出 CSV，不得只保留截图。

### 8.4 统计规则

1. 平均 FPS：稳态区间内每秒 FPS 的算术平均值。
2. 1% Low FPS：将帧时间升序排列，取第 99 百分位帧时间 `T99`，按 `1000 / T99` 计算。
3. 帧时间 P95：第 95 百分位帧时间。
4. 卡顿率：帧时间大于 50ms 的帧数除以总帧数。
5. 内存增长：`(结束 PSS − 第 10 秒 PSS) / 第 10 秒 PSS × 100%`。
6. CPU 峰值：所有 1 秒窗口 CPU 使用率的最大值。
7. 启动耗时：从 `tt.onLaunch` 时间戳到首帧渲染完成时间戳；端到端耗时另记，不替代前者。
8. 中位数：奇数取中间值，偶数取中间两值平均。
9. 渲染耗时：优先取 LayaAir 独立渲染统计或 Perfdog GPU 时间；无法采集时使用帧时间 P95 代替，并在记录中注明“替代口径”。

## 9 判定标准

### 9.1 单用例判定

| 结果   | 条件                                                 |
| ------ | ---------------------------------------------------- |
| 通过   | 实际结果与预期完全一致，证据完整                     |
| 不通过 | 实际结果与预期不一致，或出现崩溃、伪造成功、静默失败 |
| 阻塞   | 环境或权限不具备，无法执行；必须记录阻塞原因与责任方 |
| 未采集 | 未执行或数据缺失；不得记为通过                       |

### 9.2 L3 通过条件

必须同时满足：

1. R-03、R-04 的所有 P0、P1 用例通过率 100%。
2. P2 用例通过率不低于 95%，且未通过项有责任人与规避方案。
3. P0/P1 缺陷数为 0；不存在崩溃、ANR、伪造平台成功、确定性哈希不一致。
4. 低、中、高三档设备的全部性能门槛指标中位数达标；任一门槛指标不达标即 L3 不通过。
5. 五类平台能力在至少一台 Android 与一台 iOS 真机上通过。
6. 真机 `stateHash` 与黄金样本 `fnv1a32:92852f6a` 一致。
7. 证据包完整：设备信息、版本、构建哈希、原始 CSV、截图、录屏、日志、缺陷清单。

### 9.3 有条件通过与不通过

- **有条件通过**：仅允许 P2 级界面/文案问题，且不影响任何 P0/P1 用例、不涉及性能门槛；必须登记责任人与关闭标准。
- **不通过**：出现任一 P0/P1 缺陷、任一性能门槛未达标、平台能力缺失、哈希不一致、证据缺失或无法复现。
- **待验收**：设备、AppID、广告位或网络任一前置条件缺失，导致关键用例无法执行。

### 9.4 复测规则

1. 环境问题导致失败：修复环境后完整重跑该用例，不改变判定阈值。
2. 代码修复导致失败：重新构建并重跑受影响用例及相关性能采样。
3. 性能不达标：允许在同构建、同设备、同环境下复测 1 次；仍不达标则判定不通过，不得通过更换设备规避。
4. 任何复测必须保留原始失败记录，不得覆盖。
