## 结果摘要

- 启动：`[L3_BOOT_OK] {"version":"3.3.0","configHash":"fnv1a32:e7ae79c0"}`，`hash()=fnv1a32:92852f6a`。
- 交互：登录/广告/分享按钮均输出 `[L3_ACTION_OK]`；`breakView()` 输出 `[L3_VIEW_ERROR]` 后 tick 继续。
- B-06：720×1280、1080×2400、1170×2532 三档 stage 均为 750×1334，节点全部在界内，无裁切、无拉伸，仅有留边。
- B-07：连续重载 10 次，每次 `[L3_BOOT_OK]` 1 次、`[L3_BOOT_FAILED]` 0 次，哈希/tick/事件数一致，单次点击仅 1 次动作。
